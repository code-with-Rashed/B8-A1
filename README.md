# B8A1 – Assignment 1: Problem Solving with TypeScript & OOP

This repository contains my solutions for [**Assignment 1**](https://github.com/Apollo-Level2-Web-Dev/B8A1) of the Next Level Web Development course (Batch 8).

The assignment focuses on fundamental TypeScript concepts, problem-solving techniques, and Object-Oriented Programming (OOP).

## Technologies Used

- TypeScript
- JavaScript (ES6+)
- Object-Oriented Programming (OOP)

## Assignment Overview

I have implemented all 8 programming problems in a single TypeScript file named `solutions.ts`, following the assignment requirements.

### Problem Solutions

| No. | Function / Class | Concepts Covered |
| --- | --- | --- |
| 1 | `multiplyValue` | Optional Parameters, Default Behavior |
| 2 | `processInput` | Union Types, Type Narrowing |
| 3 | `formatCoordinate` | Readonly Tuples |
| 4 | `concatenateArrays` | Generics, Rest Parameters |
| 5 | `getPopularCourses` | Interfaces, Array Filtering |
| 6 | `pluckValues` | Generics, `keyof` Constraint |
| 7 | `Employee` & `Manager` | Classes, Inheritance, Access Modifiers |
| 8 | `validateAgeAsync` | Async/Await, Promises, Error Handling |

## Key TypeScript Concepts Practiced

Through these solutions, I practiced:

- Writing explicit parameter and return types.
- Working with optional parameters.
- Handling union types using `typeof`.
- Using readonly tuples.
- Implementing generic functions.
- Defining and using interfaces.
- Applying `keyof` constraints.
- Understanding class inheritance.
- Using `private` and `protected` access modifiers.
- Handling asynchronous operations with Promises.

## How to Run the Solutions

### 1. Clone the repository

```bash
git clone https://github.com/code-with-Rashed/B8-A1.git
```

### 2. Navigate to the project directory

```bash
cd B8-A1
```

### 3. Install TypeScript globally (if not already installed)

```bash
npm install -g typescript
```

### 4. Compile the TypeScript file

```bash
tsc solutions.ts --target ES2017
```

After successful compilation, the compiler generates a JavaScript file named `solutions.js`.
